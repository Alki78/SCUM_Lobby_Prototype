# SCUM / Community Rework — v0.6.0

Cette version marque la finalisation graphique de l'onglet SOLO.

Nouveautés :

- Interface SOLO harmonisée avec l'ACCUEIL.
- Quatre parcours SOLO finalisés visuellement.
- Nouvelles compositions pour le chargement des sauvegardes, la nouvelle partie et le tutoriel.
- Illustrations dédiées et mise en page adaptée aux différentes résolutions.
- Conservation des interactions de démonstration.

Le prototype reste une maquette interactive indépendante, sans connexion au jeu SCUM ni gestion réelle des sauvegardes.

Le fichier HTML fonctionne de manière autonome, sans installation ni serveur local.
